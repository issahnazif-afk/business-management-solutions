# Business Management Solutions (pitch version)

CRM for small companies, ERP for factories, and CRM + ERP for large factories. Runs on GitHub Pages with no server.

## Publish
1. Create a new GitHub repository, separate from Amal Connect.
2. Upload the contents of this folder with `index.html` at the root.
3. Settings → Pages → deploy from `main`, folder `/ (root)`.

## Limits of this version
- Records stay in the browser where they were entered. Use Users and data → Download backup to move them.
- Instagram, TikTok, WhatsApp, Facebook and the ChatGPT/Claude MCP connection need a server. The Chat automation page tests the conversation handling.
- Use test data only.
- Tax rates are editable starting values. Confirm them before use.
